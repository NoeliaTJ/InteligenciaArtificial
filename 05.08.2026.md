Sugerencias Automáticas
He ido familiarizándome con las funcionalidades de autocompletado:

Bloque de Sugerencia (Ghost Text)
Completando la línea actual, sugiere un nuevo bloque de código completo
Si trabajas en un bloque de código, se muestra un fragmento atenuado
Colocar el puntero sobre la sugerencia muestra el panel de control  

Navegación en las Sugerencias
Panel de control → Flechas:
| ← Sugerencia anterior
| → → Sugerencia siguiente
Atajos de Teclado
Sistema	Siguiente	Anterior
macOS	⌥ (Opción) o Alt+]	⌥ (Opción) o Alt+[
Windows/Linux	Alt+]	Alt+[

Comandos de la CLI
Comando	Descripción
/help	Muestra todos los comandos disponibles
/explain <command>	Explica cualquier comando de shell
/suggest <task>	Suggeste un comando para una tarea
/revise	Revisa la última sugerencia
/feedback	Envía feedback sobre una respuesta
/exit	Salir del modo interactivo
/model <model>	Cambia el modelo de IA
/theme [auto|dark|light]	Cambia el tema del terminal
/skills	Verifica aptitudes habilitadas
/mcp	Configuración del servidor MCP
/list-dirs	Ver directorios permitidos
/reset-allowed-tools	Restablece herramientas permitidas  

Flujos de Trabajo de Ejemplo
bash
# Tareas exploratorias
/suggest un comando → /explain ese comando → /revise si es necesario → /feedback → /exit

# Uso interactivo
/exit al terminar
Configuración con /
bash
/model     → Elegir modelo de IA
/theme     → Cambiar tema del terminal
/skills    → Admin funcionalidades
/reset-allowed-tools → Reiniciar

Entornos Aislados
Característica	Local	Cloud
Ubicación	Máquina local	Entorno de GitHub
Uso de recursos	Locales	En la nube
Aislamiento	Restringido	Totalmente aislado
Independencia	No	Sí
Cargas paralelas	Limitado por hardware	Escalable

bash

Comparativa de Superficies
Superficie	Para qué es mejor	Rol clave
GitHub Copilot app	Flujos de trabajo de agentes completos	Coordina: problema → código → PR → merge
Copilot en VS Code	Edición y depuración de código	Desarrollo práctico
Copilot CLI	Flujos en terminal	Automatización y control de entorno
Copilot en GitHub.com	Colaboración y planificación	Issues, PRs, coordinación  

Tipos de Modos de Sesión
Modo	Descripción	Para qué
Interactive	Propone cambios, espera aprobación	Desarrollo colaborativo
Plan	Planifica antes de ejecutar	Tareas complejas que requieren revisión
Autopilot	Actúa solo, implementa	Trabajo bien definido, tareas rutinarias
