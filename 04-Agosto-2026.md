## Funcionalidades

- Las sugerencias de Copilot se pueden omitir con el tabulador.
- Con Command + i se puede interactuar con el chat en línea sin salir del código.
- Dentro del panel de chat / chat en línea se pueden usar comandos con slash `/`

> /test te ayuda a escribir pruebas  
> /docs está pensado para escribir documentos.  
> /explain obtiene explicaciones sobre el código.
> /generate genera código para responder a la pregunta especificada.
> /help obtiene ayuda sobre cómo usar el chat de Copilot.
> /optimize analiza y mejora el tiempo de ejecución del código seleccionado.
> /tests crea pruebas unitarias para el código seleccionado.
> /fix te da respuestas para arreglar lo que tengas delante.
> con `@terminal` puedes hablar con GitHub Copilot para interactuar con el terminal como agente.
