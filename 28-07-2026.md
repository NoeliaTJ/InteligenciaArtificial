## Sugerencias en línea.
Las sugerencias que ofrece Copilot aparecen como texto atenuado delante del cursor.
* Para aceptar una sugerencia, selecciona la tecla Tab o la tecla > (flecha derecha).
* Para rechazar una sugerencia, siga escribiendo o seleccione la tecla Esc.

## Paleta de comandos
1. Abre la paleta de comandos en Visual Studio Code seleccionando Ctrl+Shift+P (Windows o Linux) o Cmd+Shift+P (Mac).
2. Escribe Copilot para ver los comandos disponibles.
3. Selecciona acciones como Explica esto o Genera pruebas unitarias para obtener ayuda.

## Chat
Formula preguntas o solicita fragmentos de código y Copilot proporciona respuestas en función de la entrada.
1. Abre el panel de chat de Copilot en el IDE.
2. Escribe preguntas o solicitudes en lenguaje natural y, a continuación, evalúa la respuesta de Copilot.

## Chat insertado
Habilita conversaciones especificas del contexto directamente en el editor de código, pudiendo solicitar modificaciones o explicaciones sin cambiar el contexto.
Te ayuda a centrarte en una sección específicafica de código.
También existen comandos para hacer acciones rápidas. Por ejemplo:
* /explain - Proporciona una explicación del código seleccionado.
* /suggest - Ofrece sugerencias de código basadas en el contexto actual.
* /tests - Genera pruebas unitarias para la función o clase seleccionada.
* /comment - Convierte los comentarios en fragmentos de código.

## Sugerencias múltiples 
Para fragmentos de código complejos, busca la bombilla y selecciona el icono o usa 
* [Alt+i] (Windows/Linux) u
* [Option+i] (Mac) para ir por todas las alternativas.

## Explicaciones
Es muy útil para códigos complejos, y cuando hay más de un integrante en el proyecto.
1. Selecciona un bloque de código.
2. Clic con el botón derecho en el bloque de código y selecciona Copilot: Explica esto en el menú contextual.
3. Lee la explicación que Copilot proporciona para el código seleccionado.

## Generación de pruebas
Mantiene la integridad del código y detecta los errores al principio del proceso de desarrollo. Para esto puedes:
1. Selecciona la función que quieras y usa la paleta de comandos para elegir Copilot: Genera pruebas unitarias.
2. Revisa los casos de prueba que Copilot sugiere para el código.
