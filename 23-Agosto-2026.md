## Voy a hacer una libreta mágica  
La libreta consiste en hacer notas de colores, que se puedan agregar, buscar, o eliminar.  
Algo muy sencillo para manejar dos agentes / aiders.  
Voy a crear una carpeta con el proyecto con:

>cd ~
>mkdir mi-libreta
>cd mi-libreta
>git init
>mkdir templates  


En esta misma terminal que tengo abierta, abro Aider con:
>aider app.py templates/index.html

## Instrucciones  
Y le doy instrucciones, justo después del > 
Crea una aplicación Flask super sencilla llamada app.py que funcione como una libreta digital:

>1. Guarda las notas en un archivo notas.json (no uses base de datos).
>2. La página principal muestra un formulario con dos campos: "título" y "contenido".
>3. Al enviar el formulario, la nota se guarda y aparece en la lista de abajo.
>4. Cada nota tiene un botón "Borrar" para eliminarla.
>5. Todo el HTML debe ir en templates/index.html y debe verse bonito pero simple (fondo claro, letra grande, botón verde para guardar, botón rojo para borrar).
>6. Usa Bootstrap desde CDN para que se vea decente sin que yo tenga que saber CSS.
>7. El archivo notas.json debe crearse solo si no existe.
>8. Añade muchos comentarios en el código en español explicando qué hace cada parte.
Mantén el código MUY simple.
