## Sugerencias Automáticas. 
Bloque de Sugerencia (Ghost Text)
Completando la línea actual, sugiere un nuevo bloque de código completo
Si trabajas en un bloque de código, se muestra un fragmento atenuado
Colocar el puntero sobre la sugerencia muestra el panel de control.  
  
## Navegación en las Sugerencias
Panel de control → Flechas:  
| Acción               | Icono |
| -------------------- | ----- |
| Sugerencia anterior  | `←`   |
| Sugerencia siguiente | `→`   |

## Modelos de IA. 
# Modelos Estándar (GPT-4o)
* Respuestas rápidas y confiables para tareas cotidianas
* 1 PRU por solicitud
* Ideal para: asistencia rutinaria, explicaciones, depuración básica
>Ejemplos:  
>Generación de funciones sencillas. 
>Ayuda de sintaxis. 
>Sugerencias básicas de refactorización. 
  
# Modelos Premium (o1-preview, o1-mini)
* Funcionalidades de razonamiento mejoradas
* 2 PRU por solicitud (doble que el estándar)
* Para: análisis sofisticados, algoritmos complejos, decisiones arquitectónicas
>Ejemplos:
>Depuración avanzada de código multiproceso. 
>Diseño de algoritmos complejos. 
>Análisis de seguridad. 
>Tareas del Agente en GitHub.com.

## Instalación de la CLI
En MacOsLinux. 
brew install copilot-cli

Script Oficial.  
curl -fsSL https://gh.io/copilot-install | bash

Iniciar en modo interactivo.  
copilot
Importante: Lo primero que aparece: "¿Confías en los archivos de esta carpeta?"
Solo puede continuar en ubicaciones de confianza (tiene permiso para leer, modificar o ejecutar archivos).

## Comandos de CLI
| Comando                | Descripción                            |          |                             |
| ---------------------- | -------------------------------------- | -------- | --------------------------- |
| `/help`                | Muestra todos los comandos disponibles |          |                             |
| `/explain <command>`   | Explica cualquier comando de shell     |          |                             |
| `/suggest <task>`      | Sugiere un comando para una tarea      |          |                             |
| `/revise`              | Revisa la última sugerencia            |          |                             |
| `/feedback`            | Envía feedback sobre una respuesta     |          |                             |
| `/exit`                | Salir del modo interactivo             |          |                             |
| `/model <model>`       | Cambia el modelo de IA                 |          |                             |
| \`/theme \[auto        | dark                                   | light]\` | Cambia el tema del terminal |
| `/skills`              | Verifica aptitudes habilitadas         |          |                             |
| `/mcp`                 | Configuración del servidor MCP         |          |                             |
| `/list-dirs`           | Ver directorios permitidos             |          |                             |
| `/reset-allowed-tools` | Restablece herramientas permitidas     |          |                             |

## Entornos aislados. 
| Característica   | Local                 | Cloud              |
| ---------------- | --------------------- | ------------------ |
| Ubicación        | Máquina local         | Entorno de GitHub  |
| Uso de recursos  | Locales               | En la nube         |
| Aislamiento      | Restringido           | Totalmente aislado |
| Independencia    | No                    | Sí                 |
| Cargas paralelas | Limitado por hardware | Escalable          |

  
ejemplos:
/sandbox enable      # Aislado local
copilot --cloud      # Aislado en la nube
